📖 Guia Rápido — NetSim Pro
✕
Adicionar Dispositivos
• Arraste da barra lateral para o canvas
• Ou dê duplo clique no dispositivo

Conectar Dispositivos
• Pressione C ou clique em 🔗
• Origem → destino: abre janela para tipo de cabo e portas
• No ping bem-sucedido aparece a cartinha ICMP seguindo o caminho na topologia

CLI / Terminal
• Selecione um dispositivo e use o terminal abaixo
• Fluxo IOS: enable → configure terminal → interface …
• Em modo config use do show … (ex.: do show ip)
• Comandos: help, show netsim-parity, ping, vlan, switchport access vlan, show vlan brief

Atalhos de Teclado
• S Modo Selecionar   C Conectar   X Excluir
• Del Excluir selecionado   Esc Cancelar
• Ctrl+Z Desfazer   Ctrl+A Selecionar tudo
• Scroll do mouse: Zoom in/out
• Arraste canvas vazio: Mover visão
